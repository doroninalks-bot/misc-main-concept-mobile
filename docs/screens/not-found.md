# Экран «Такого экрана нет» (`*`)

## Назначение

Служебный экран заготовки: показывается на любом адресе, которого нет в
`src/routes.tsx`, — опечатка в ссылке или экран переименовали. Остаётся в
каждом прототипе, первым экраном не заменяется.

## Файлы

- `src/screens/not-found/not-found.tsx`
- `src/screens/not-found/not-found.css`
- маршрут `*` в `src/app.tsx`

## Состояния и поведение

Одно состояние. Кнопка ведёт на первый экран сценария (`/`). На канвас не
выносится: это не шаг сценария.

## Данные

Нет.
