# Ветки, коммиты и ссылки

Для дизайнера. Как устроена история прототипа и откуда берутся ссылки для
респондентов. Команды за вас выполняет агент — достаточно сказать ему, что
нужно, своими словами. Но понимать, что происходит, полезно: так проще решать,
что показывать на тесте и куда откатиться.

## Коротко

- **Коммит** — сохранённая точка в истории. К любой можно вернуться.
- **Ветка** — отдельная линия правок. Пока вы в ней, `main` не меняется.
- **`main`** — основная ветка. Её адрес на Vercel — ссылка для респондентов.
- **Пуш** — отправить коммиты на GitHub. После пуша Vercel сам пересобирает
  прототип, через минуту ссылка показывает новое.

## Ссылки

| Что | Адрес | Кому |
|---|---|---|
| `main` | `<имя>.vercel.app` | респондентам, в сценарий теста |
| любая другая ветка | `<имя>-git-<ветка>-<команда>.vercel.app` | вам и команде, для сравнения |

Адрес ветки Vercel создаёт сам, как только ветку запушили. Точный адрес — в
проекте на Vercel, вкладка **Deployments**, или спросите агента.

Ссылки веток по умолчанию закрыты входом в Vercel — респондент их не откроет.
Для теста ветку либо сливают в `main`, либо открывают защиту в **Settings →
Deployment Protection**. Решение за вами.

## Варианты гипотезы

Два варианта одного экрана — две ветки, а не два экрана рядом:

- `main` — текущий вариант;
- `variant/short-form` — вариант с короткой анкетой.

Так у каждого варианта своя ссылка, а код не превращается в набор условий
«если вариант А, то…». Имя ветки — `variant/` и коротко, что меняется, латиницей
через дефис.

Победил вариант — ветку сливают в `main`. Проиграл — ветка остаётся в истории,
удалять её не обязательно.

## Что сказать агенту

| Хочу | Скажите |
|---|---|
| Сохранить сделанное | «закоммить» |
| Сохранить и обновить ссылку | «закоммить и запушь» |
| Попробовать вариант, не трогая основной | «сделай ветку под вариант с …» |
| Вернуться к основному | «переключись на main» |
| Показать вариант респондентам | «слей ветку в main и запушь» |
| Посмотреть, что изменилось | «покажи, что изменилось с прошлого коммита» |
| Откатить неудачную правку | «верни как было до …» |

Перед пушем агент показывает, что меняется, одним списком. Перед слиянием в
`main` — всегда спрашивает: после него меняется ссылка респондентов.

## Сообщения коммитов

По-русски, одной строкой, что изменилось для человека: «Паспорт раскрывается
первым», а не «fix accordion state». По истории потом ищут, когда что
поменялось, — сообщение должно читаться без кода.
