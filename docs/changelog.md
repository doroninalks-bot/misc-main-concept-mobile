## 28.10.2026

- Главная: пагинация — окно из пяти точек, текущая по центру (у краев ленты — первой или последней), крайняя точка меньше, если за ней есть еще баннеры; окно плавно сдвигается при смене.
- Главная: баннеров теперь семь, по компоненту «banners» в Фигме (22874:31062) — вход, вклад, бонус 1000 Б, займ, кэшбэк, ОСАГО, отзыв об автодилере; у всех новые иллюстрации, градиенты из макета (синий и фиолетовый), у соседних нет рамки. Фон в варианте 1 — в цвет карточки.
- Панель «Плавность»: порог свайпа можно поставить в 0, по умолчанию теперь 0 (было 40 px) — листает любой свайп.
- Главная: свайп карусели вбок на телефоне больше не прокручивает страницу и не тянет «потяните для обновления», даже по диагонали; вертикальный жест по карусели прокручивает страницу как раньше.
- Панель «Плавность»: новый ползунок «Свайп: путь пальца для перелистывания» (по умолчанию 40 px) — свайп короче возвращает баннер на место, даже быстрый, от порога листает хотя бы на соседний.
- Главная: цвета баннеров переставлены — вход синий, вклад и займ фиолетовые (фон в варианте 1 следом); параллакс картинки по умолчанию 40 px (было 12).
- Главная: два варианта — `/` (фон по умолчанию меняет цвет вслед за баннером) и `/main-v2` (фон всегда синий); у каждого свои сохраненные настройки панели «Плавность», на канвасе — по шагу на вариант.
- Главная: смена цвета фона больше не тормозит смену баннеров на телефоне — размытые пятна фона теперь готовые картинки, а не размытие SVG, которое пересчитывалось каждый кадр.
- Главная: третий баннер (был серый «Вклад») — фиолетовый, как «Войдите в аккаунт», с текстом «Оформите первый займ / без процентов»; при включенной смене цвета фон у него тоже фиолетовый.
- Главная: инерция свайпа — затухание по умолчанию 100 мс (было 325), лента после броска останавливается быстрее.
- Главная: градиент по бокам плавнее — прозрачность по S-кривой без заметной границы, полоса 40 px.
- Главная: градиент по бокам легче — полоса 32 px вместо ~53, у края карточка видна на 40%, а не исчезает.
- Главная: карточки по бокам уходят в градиент к краям экрана, по умолчанию включено; выключает галочка «Без размытий» в панели «Плавность» (она же убирает размытие у точек пагинации).
- Баннеры: заливка — круговые градиенты из компонента «banners» в Фигме (22915:22967) вместо цвета с размытой подсветкой; подсветки убраны.

## 27.10.2026

- Главная: свайп по инерции (бывший вариант 5) стал основным на `/`; варианты 3, 4 и 5 удалены вместе с кодом и рамками на доске.
- Главная, вариант 5 `/main-v5`: свайп по инерции, как колесо выбора времени в iOS, — сильный бросок пролистывает несколько баннеров. На доске своя секция «Свайп по инерции».
- Главная: параллакс картинки баннера по умолчанию 12 px (было 48, 32, 64).
- Главная: фон героя больше не меняет цвет при смене баннера, всегда синий, как у «Вкладов» (решение дизайнера: подозрение на подвисание). Вернуть — «Менять цвет фона» в панели «Плавность».
- Главная: убран рывок на смене баннера — ушедшие за экран баннеры прозрачны не до нуля (0,001), поэтому браузер держит их нарисованными и не рисует заново в первом кадре смены. Замер в Chrome (телефон 390 × 844, плотность 3x, процессор ×4 медленнее): первая смена — кадр 233 мс до правки, ≤ 17 мс после.
- Главная: смены с участием «Войдите в аккаунт» шли рывками, а между «Вкладами» — плавно, потому что менялся фон героя (его доля писалась из JS каждый кадр). Теперь цвет фона меняется CSS-переходом прозрачности на видеокарте, с длительностью и кривой из панели.
- Главная: настройки панели «Плавность» применяются ко всем переходам между всеми тремя баннерами, включая замыкание 3 → 1. Фон героя теперь едет по той же позиции ленты, что и баннеры (раньше — свой таймер 900 мс). Доезд после свайпа настраивается отдельно: кривая и доля длительности.
- Главная: рывки при смене баннера (и при свайпе, и при автосмене) — фон героя теперь двумя готовыми слоями с перетеканием прозрачности (раньше цвет размытого SVG перерисовывался каждый кадр); внутри баннера двигаются только transform и прозрачность на отдельных GPU-слоях; скругление, цвет синего и ширина текста переключаются разом на середине пути.
- Главная: свайп отзывчивее — короткий быстрый свайп (от ~40 px) листает баннер, доезд после пальца стартует сразу, без паузы; длительность по умолчанию 500 мс, инерция броска 0,3.
- Главная: смена баннера идет по времени и кривой с разгоном и торможением (раньше — затухание с резким стартом). В панели «Плавность» можно выбрать режим, длительность, кривую и отключить плавную ширину текста.
- Главная: карусель переписана на непрерывную позицию — убран скачок при смене баннера. Масштаб, цвет, подсветка и текст баннера идут от одного числа, а не от переключения класса. В панели «Плавность» вместо длительности и кривой — затухание доезда и инерция броска.
- Главная: справа снизу панель «Плавность» (сворачивается в кнопку) — длительность, кривая, параллакс, порог свайпа, слои GPU, отключение размытий. Сдвиг за пальцем теперь пишется в CSS-переменную без перерисовки React на каждое движение — меньше рывков при свайпе.
- Баннеры: за пальцем картинка больше не отстает от карточки, не «болтается» при быстром движении.
- Главная: убраны рывки при прокрутке — размытый фон героя на своем слое, полоса пагинации анимируется через transform.
